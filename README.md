# kerpo-skills

Personal daily-driver skill collection for AI coding agents — works with
**Claude Code**, **Cursor**, and **OpenCode** (and any other Agent
Skills-compatible harness). All skills use the `kerpo-` prefix. MIT licensed.

## Install

Requires [apm](https://microsoft.github.io/apm/) (the Agent Package Manager):

```bash
brew install apm          # macOS
curl -sSL https://aka.ms/apm-unix | sh   # Linux / macOS without Homebrew
```

### Install for one project (workspace/repo scope)

Run in your project root — skills land in the project and are shared by all
harnesses:

```bash
apm install KerpoOrg/kerpo-skills
```

This adds the package to your project's `apm.yml` (commit it and
`apm.lock.yaml`) and deploys skills to:

| Harness | Project location |
| ------- | ---------------- |
| Claude Code | `.claude/skills/` |
| Cursor | `.agents/skills/` |
| OpenCode | `.agents/skills/` |

### Install globally (user scope)

Install once into your home folder and the skills are available in every
project:

```bash
apm install -g KerpoOrg/kerpo-skills
```

| Harness | Global location |
| ------- | --------------- |
| Claude Code | `~/.claude/skills/` |
| Cursor | `~/.agents/skills/` |
| OpenCode | `~/.config/opencode/skills/` |

### Update

```bash
# project scope
apm update KerpoOrg/kerpo-skills && apm install

# user scope
apm install -g KerpoOrg/kerpo-skills --update
```

### Install only a subset

```bash
apm install KerpoOrg/kerpo-skills --skill kerpo-tdd --skill kerpo-git-context
```

## Development (maintainer)

Requires [mise](https://mise.jdx.dev). Tools (apm, jq, shellcheck, bats,
opencode) are pinned in `mise.toml` and installed automatically.

```bash
# Create a new skill
./scripts/new-skill.sh kerpo-my-skill

# Validate all skills (unicode/structure, no evals)
mise run skills -- audit

# Test trigger accuracy on a free OpenCode model (after filling eval_queries.json)
./scripts/test-triggers.sh kerpo-my-skill

# Run output quality evals on a free OpenCode model (after filling evals.json)
./scripts/run-evals.sh kerpo-my-skill 1

# Deploy locally to this repo (pack → install project scope)
mise run skills -- install

# Deploy globally to user scope (pack → install -g)
mise run skills -- install --global

# Remove deployed kerpo-* skills (scoped, never touches other skills)
mise run skills -- uninstall --yes
mise run skills -- uninstall --yes --global

# Lint/test mise file tasks
mise run ci -- lint
mise run ci -- test
```

## Repo structure

```
.apm/skills/kerpo-<name>/
├── SKILL.md                    # skill instructions (max 500 lines / 5000 tokens)
├── references/                 # detailed reference material (loaded on demand)
├── scripts/                    # executable code bundled with the skill
├── assets/                     # templates, static resources
└── evals/
    ├── evals.json              # output quality test cases
    ├── eval_queries.json       # trigger accuracy test queries
    └── trigger-results.json    # generated by test-triggers.sh
```

See [.claude/CLAUDE.md](.claude/CLAUDE.md) for the full development workflow.

Evals run against free OpenCode Zen models (`opencode auth login` once); see
[docs/evals.md](docs/evals.md). The `skills-evals.yml` workflow runs them nightly
and on demand.

## Adding a dependency on another APM package

```yaml
# apm.yml
dependencies:
  apm:
    - kerpo/other-package@v1.0.0
```

## Git conventions

Commit: `apm.yml`, `apm.lock.yaml`, `.apm/`  
Ignore: `apm_modules/`, `*-workspace/`, `build/`, `.agents/skills/`, `.claude/skills/`
