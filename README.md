# kerpo-skills

Kerpo Organization private APM skill package for Claude Code and Cursor. All skills use the `kerpo-` prefix.

## Install in your project

Requires [mise](https://mise.jdx.dev) and [gh](https://cli.github.com) authenticated to a KerpoOrg account.

**1. Add to your project's `mise.toml`:**

```toml
[tools]
"github:microsoft/apm" = "0.28.0"

[env]
GITHUB_APM_PAT_KERPOORG = "{{ env.GITHUB_APM_PAT_KERPOORG }}"

[tasks.skills-auth]
description = "Write GITHUB_APM_PAT_KERPOORG to mise.local.toml from gh keyring"
run = """
TOKEN=$(gh auth token 2>/dev/null)
if [ -z "$TOKEN" ]; then
  echo "Error: not logged in. Run: gh auth login" >&2
  exit 1
fi
printf '[env]\nGITHUB_APM_PAT_KERPOORG = "%s"\n' "$TOKEN" > mise.local.toml
echo "mise.local.toml updated"
"""

[tasks.skills-install]
description = "Install kerpo-skills"
run = "apm install KerpoOrg/kerpo-skills"

[tasks.skills-update]
description = "Update kerpo-skills to latest"
run = "apm update KerpoOrg/kerpo-skills && apm install"
```

Lisää `mise.local.toml` gitignooreen.

**2. Autentikoidu (kerran):**

```bash
gh auth login        # jos ei vielä kirjautunut KerpoOrg-tilille
mise run skills-auth # kirjoittaa tokenin mise.local.toml:iin
mise trust mise.local.toml
```

**3. Asenna:**

```bash
mise run skills-install
```

**Päivitä:**

```bash
mise run skills-update
```

Skills are installed to `.agents/skills/` (shared across Claude Code, Cursor, and other harnesses). Commit `apm.yml` and `apm.lock.yaml` — gitignore `.agents/skills/` since it is generated.

## Quick start

```bash
# Create a new skill
./scripts/new-skill.sh kerpo-my-skill

# Validate all skills (unicode/structure, no evals)
mise run skills -- audit

# Test trigger accuracy (after filling eval_queries.json)
./scripts/test-triggers.sh kerpo-my-skill

# Run output quality evals (after filling evals.json)
./scripts/run-evals.sh kerpo-my-skill 1

# Deploy locally (pack → install local bundle)
mise run skills -- install

# Lint/test mise file tasks
mise run ci -- lint
mise run ci -- test
```

## Repo structure

```
.apm/skills/kerpo-<name>/
├── SKILL.md                    # skill instructions (max 500 lines / 5000 tokens)
├── references/                 # detailed reference material (loaded on demand)
├── scripts/                    # executable code bundled with the skill
├── assets/                     # templates, static resources
└── evals/
    ├── evals.json              # output quality test cases
    ├── eval_queries.json       # trigger accuracy test queries
    └── trigger-results.json    # generated by test-triggers.sh
```

## Adding a dependency on another APM package

```yaml
# apm.yml
dependencies:
  apm:
    - kerpo/other-package@v1.0.0
```

## Git conventions

Commit: `apm.yml`, `apm.lock.yaml`, `.apm/`  
Ignore: `apm_modules/`, `*-workspace/`, `build/`, `.agents/skills/`, `.claude/skills/`
